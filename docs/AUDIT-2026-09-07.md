# Audit dan perbaikan Kana — 7 September 2026

> Catatan historis: audit ini merekam keadaan sebelum rilis stabil 0.2.0.
> Penyebutan versi prerelease di bawah adalah konteks pemeriksaan saat itu,
> bukan versi paket yang saat ini diterbitkan.

Audit ini memeriksa autentikasi, relay Hermes, input API, penyimpanan percakapan
dan aktivitas, serta jalur render riwayat. Acuan arsitektur adalah AGENTS.md,
PLAN.md, panduan Next.js terpasang, dan kontrak event di source Hermes lokal
yang dibaca tanpa perubahan. Ini bukan sertifikasi keamanan seluruh aplikasi.

## Temuan yang diperbaiki

| Area | Masalah sebelum perbaikan | Perubahan |
| --- | --- | --- |
| Keamanan sesi | Password berubah tetapi token lama tetap berlaku sampai kedaluwarsa | Versi sesi acak disimpan atomik bersama hash, diverifikasi setiap request dan heartbeat SSE; login tertunda tidak bisa memperoleh versi password baru |
| Login | Banyak request bisa melewati pemeriksaan lock sebelum bcrypt selesai | Reservasi sinkron membatasi satu pemeriksaan; request bersamaan menerima 429 dan Retry-After |
| Password/JWT/cookie | Password baru panjang terpotong diam-diam oleh bcrypt, verifikasi JWT tidak mewajibkan seluruh klaim, HTTPS langsung tidak memasang Secure | Batas 72 byte UTF-8 untuk password baru, HS256 serta klaim autentikasi/iat/exp wajib, deteksi URL HTTPS langsung |
| Input API | request.text/json mengalokasikan seluruh body sebelum batas diperiksa; raw.length menghitung unit string; JSON null bisa memicu 500 | Pembaca JSON object bersama membatasi byte di stream, membatalkan input besar dengan 413, dan menolak bentuk JSON salah dengan 400 |
| Aktivitas | Angka yang terkoersi dari string/boolean atau melebihi integer aman bisa masuk ke penyimpanan | Validasi tipe numerik dan integer aman sebelum menyentuh SQLite |
| SSE | Abort saat connect bisa terlewat; listener/timer dapat bocor; antrean pembaca lambat tidak dibatasi | Kepemilikan lifecycle di satu modul, cleanup idempoten sejak awal, pembatalan saat connect, dan batas antrean 16 MiB |
| State percakapan | Map Zustand global dibagi semua instance dan dimutasi sebelum disalin, padahal controller tidak memakai subscription store tersebut | Map privat per instance dengan interface ConversationStore yang sama; Hermes tetap pemilik transcript |
| Render riwayat | Intl.DateTimeFormat dibuat untuk setiap pesan/sesi setiap render | Satu formatter per komponen/locale lewat useMemo |

Batas body: login/pergantian password 4 KiB, RPC/aktivitas 2 MiB, speech 256 KiB.
Pemeriksaan mencakup request chunked tanpa Content-Length dan UTF-8 yang
terbelah antar-chunk. Batas ini tidak mengubah batas audio atau upload multipart.

## Dampak operasional

- Browser yang mengubah password mendapat cookie pengganti. Browser lain perlu
  login ulang; SSE lama berhenti pada heartbeat berikutnya, maksimal 25 detik.
- Hash password lama tetap diterima, termasuk hasil migrasi auth.json. Batas
  panjang berlaku saat menetapkan password baru.
- Reload/remount memulihkan transcript dari Hermes. Isi subtitle historis
  tidak diubah atau diterjemahkan ulang.
- Tidak ada dependency baru, perubahan source/instalasi Hermes, atau lokasi
  data server baru. Refactor penuh controller E2–E5 tetap pekerjaan terpisah.

## Verifikasi

- Baseline sebelum perubahan: lint bersih dan 146 tes lulus.
- Sesudah perubahan: lint, `tsc --noEmit`, dan 164 tes lulus (18 tes regresi baru).
- `npm run test:e2e`: 32/32 skenario desktop/mobile lulus, termasuk subtitle
  historis, restore transcript, draft per percakapan, slash keyboard, dan auth.
- `npm run package:local`: build produksi dan perakitan standalone berhasil.
- Uji HTTP pada standalone dengan data sementara: login, penolakan RPC JSON
  null, ganti password, penolakan token/password lama, dan akses token/password
  baru semuanya lulus. Server uji dihentikan dan data sementara dibersihkan.
- `npm run test:hermes:restart`: Hermes nyata pada home/port sementara berhasil
  membuat sesi dan resume setelah restart; home sementara dibersihkan dan data
  Hermes pengguna tidak disentuh.
- Benchmark inferensi TTS target hardware, Live2D jaringan resmi, PWA produksi,
  dan gate dogfood tujuh hari tidak dijalankan pada audit ini. Tidak ada klaim
  perubahan angka latency atau FPS; optimisasi formatter mengurangi alokasi.

## Pemeriksaan alur npm

- Paket dari build lokal diuji dengan `prepare-npm-package.mjs` dan
  `npm-package-smoke.mjs`: pack, instalasi global ke prefix sementara, alias
  `kana`/`kana-alya`, doctor, startup, login, onboarding, pergantian password,
  serta discovery/start Hermes melalui executable fixture semuanya lulus.
  Ukuran arsip sekitar 32 MB; runtime sudah dibangun sebelum instalasi.
- Registry saat pemeriksaan masih menyediakan `0.2.0-alpha.1` untuk tag
  `latest` dan `next`, dipublikasikan 30 Agustus 2026. Versi tersebut diinstal
  langsung dari registry ke prefix sementara dan dijalankan dari working
  directory terpisah dengan home/data baru. Instalasi dan startup lulus.
- **Perbedaan rilis publik:** konfigurasi local pada paket registry melaporkan
  `authEnabled: false`, `insecureNoAuth: true`; halaman utama dan API setup/config
  dapat diakses tanpa cookie. `/login` mengalihkan ke `/`, sedangkan password
  default ditolak. Ini berbeda dengan source/build lokal sekarang yang selalu
  mewajibkan autentikasi. Perbaikan lokal belum tersedia melalui instalasi npm
  publik sampai versi baru diterbitkan; audit ini tidak memublikasikan paket.
- Bukti runtime berasal dari host Linux x64 glibc 2.35, Node 22.22.2. Batas
  paket adalah Linux x64/glibc dan Node >=22.13; belum ada matriks uji terpisah
  untuk Ubuntu, Debian, Arch, Fedora, atau distribusi lain. Hermes tetap
  instalasi eksternal dan pengujian npm tidak menyintesis audio Qwen nyata.
