# Audit TTS dan distribusi — 2026-09-08

## Temuan dan perbaikan

1. ID request TTS memanggil `crypto.randomUUID()` langsung. API tersebut
   [memerlukan secure context](https://developer.mozilla.org/en-US/docs/Web/API/Crypto/randomUUID),
   sehingga akses HTTP melalui IP/LAN dapat gagal sebelum fetch. TTS sekarang
   memakai pembuat ID korelasi yang memiliki fallback; pengecekan UUID memakai
   `typeof ... === "function"`. ID ini bukan token autentikasi.
2. Satu slot pesan tertahan dapat tertimpa respons berikutnya. Antrean baru
   menyimpan setiap respons dan menampilkannya satu kali saat audio masing-masing
   mulai diputar. Kegagalan konstruksi provider maupun playback tidak merusak
   antrean berikutnya. Stop, disconnect, dan pergantian percakapan membatalkan
   audio tertunda; penghapusan percakapan tidak menghidupkan kembali pesannya.
3. Penggantian pengaturan voice membuat AudioContext baru dan kehilangan
   unlock dari interaksi pengguna. Provider playback sekarang dipertahankan;
   voice dan delivery mode dikirim per ucapan. Kegagalan lama tidak dapat
   menghentikan playback yang lebih baru.
4. Workspace tidak merender error controller, dan tombol Stop hilang ketika
   Hermes sudah selesai tetapi TTS masih bekerja. Pesan error sekarang terlihat
   dan status/Stop mencakup sintesis serta playback. Teks ditampilkan sebagai
   fallback ketika suara gagal; tidak ada klaim sukses suara palsu.
5. Callback avatar yang berubah pada setiap render memasang ulang canvas,
   mengulang pemuatan model dan dapat menimpa error suara dengan error avatar.
   Callback preferensi distabilkan. Balasan identik untuk pertanyaan baru juga
   tidak lagi dibuang oleh deduplikasi lintas giliran.
6. Runtime menganggap proses/HTTP 200 berarti model siap. Kini menunggu health
   `ready`, menampilkan error model yang sebenarnya, menangani spawn error,
   dan memakai startup timeout yang terbaca di config. Timeout atau pembatalan
   satu pengguna tidak mematikan proses download/warmup bersama.
7. Konfigurasi provider tidak aktif dapat menggagalkan provider pilihan.
   `tts.provider` kini memilih blok yang divalidasi/dipakai; keduanya boleh
   tersimpan, tetapi wajib ada selector bila kedua blok disediakan. Pembatalan
   mengikuti provider request awal, bukan config yang kebetulan aktif kemudian.
8. Penyiapan suara lokal sekarang meneruskan abort sampai discovery/registrasi,
   memakai default voice layanan yang valid, dan memulihkan referensi bawaan
   setelah direktori instalasi paket berpindah.
9. Uji nyata dengan cache lengkap dan `HF_HUB_OFFLINE=1` menghasilkan 503:
   wrapper Qwen tetap mencoba metadata jaringan. Inspeksi `qwen-tts==0.1.1`
   menunjukkan revision/cache tidak diteruskan ke seluruh processor/tokenizer.
   Kana kini menyelesaikan satu snapshot revisi lebih dahulu dan memberikan
   direktori snapshot itu ke loader resmi. Tidak ada patch pada paket Qwen atau
   instalasi Hermes. Uji yang sama kemudian berhasil offline.

## Distribusi dan konfigurasi

Mengikuti pemisahan private source app dan public CLI pada 9router, root
`package.json` kini private `kana-app`; `cli/package.json` adalah manifest npm
`kana-alya`. Launcher/config tetap punya satu sumber, disalin saat packaging.
`kana` membuka browser lokal; `kana serve` berjalan foreground tanpa browser
untuk service manager. VPS boleh memasang npm langsung atau memakai seluruh
artifact standalone hasil build sendiri. Tidak diperlukan dua instalasi sekaligus.

Tidak ada format config pengganti. Penambahan opsional:
`tts.timeoutSeconds` (default 900) dan
`tts.qwen3Local.startupTimeoutSeconds` (default 600), dalam detik, 1–3600.
Dokumentasi Nginx memakai timeout 910 detik. Config lama tetap terbaca, kecuali
kedua blok provider tanpa selector kini ditolak karena ambigu.

Lihat [instalasi/deployment](INSTALLATION.md) dan [config](CONFIGURATION.md).
Satu proses Kana per data root diperlukan untuk custody socket Hermes dan
pembatalan request. `qwen3-local` berarti lokal terhadap **server Kana**,
termasuk VPS, sedangkan Web Audio/Live2D berjalan di browser pengunjung.

## Bukti verifikasi

- 178 pengujian TypeScript/Node lulus, mencakup routing kedua provider dari
  config, pembatalan pemilik request, antrean, model loading/error, registrasi
  suara, perpindahan lokasi referensi bawaan, dan kegagalan instalasi dependency.
- 38 perjalanan browser desktop/mobile lulus, ditambah 4 pengujian baru untuk
  Stop dan pemulihan balasan identik setelah kegagalan: total 42 kasus.
- Pengujian browser TTS memakai fixture WAV dengan decoding dan Web Audio asli;
  memastikan teks belum terlihat saat sintesis tertahan dan analyser menerima
  sampel audio sesudah playback mulai. Ini menguji jalur lip sync, bukan gerak
  model Live2D eksternal karena aset model diblokir pada suite deterministik.
- 13 pengujian Python lulus, termasuk snapshot revisi/offline.
- Instalasi Python baru dari `uv.lock` dengan `--frozen` berhasil. Torch
  2.13.0+cpu dan torchaudio 2.11.0+cpu berhasil diimpor bersama. Tidak ada
  perubahan dependency berdasarkan dugaan ketidakcocokan versi.
- Sintesis Qwen nyata lewat POST relay terautentikasi, Python environment baru,
  data root/port sementara, dan cache pinned yang sudah tersedia:
  HTTP 200, 80.684 byte WAV, mono 24 kHz, 1,68 detik, RMS 0,02816,
  peak 0,17465. Elapsed 156.780 ms termasuk startup pertama di CPU.
  Ini satu sampel, bukan benchmark p50/p95 atau penilaian intelligibility.
- Paket npm benar-benar dipack, dipasang global pada prefix sementara, lalu
  diuji login/password, discovery Hermes fixture, launcher lokal dan
  `kana serve` dari direktori lain dengan data root deployment terpisah.
- Satu pengujian PWA produksi lulus untuk installability dan shell offline.
- Lint, TypeScript, build produksi dan perakitan standalone diperiksa setelah
  perubahan. Perbaikan ini merupakan ruang lingkup rilis stabil 0.2.0.

API eksternal diuji melalui fixture kontrak HTTP dan adapter, bukan panggilan
berbayar ke akun pengguna. VPS nyata, GPU, seluruh distro Linux, dan benchmark
Qwen panjang tetap membutuhkan pengujian pada lingkungan target. Hasil itu
menentukan perluasan klaim dukungan lingkungan, bukan kanal rilis terpisah.
